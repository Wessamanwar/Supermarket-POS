# Carrefour POS — Software Engineering Project (CSCI313)

A modular Point of Sale (POS) desktop application built with Python (`tkinter`) for managing supermarket inventory, shopping cart operations, discounts, taxes, and daily sales reports.

- **Ziad:** Inventory Management (`inventory.py`)

- **Omar:** Main GUI & Dashboard (`main.py`)
